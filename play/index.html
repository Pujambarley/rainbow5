Guess Distribution

Guess the Rainbow5 word in 6 tries.

  • Each guess must be a valid 5-letter word.
  • Each position in the answer owns one permanent Rainbow color.
  • After each guess, the helper row shows which answer letters appeared somewhere in your guess.
  • The colors do not tell you which guessed letter caused the match.
  • The answer will contain no repeat letters.

Color Order

The first answer letter is Red, the second Orange, then Yellow, Green, and Blue.
